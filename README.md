# 🏥 SmartCare – Caretaker Management System

A comprehensive web-based Caretaker Management System designed to connect **Clients, Caretakers, HR Managers, and Admin** through a centralized digital platform.

---

## 📌 Project Overview

SmartCare is a web-based platform developed to streamline the management of caretaker services such as:

- 👵 Elder Care  
- 👶 Babysitting  
- 🧹 Maid Services  

The system replaces manual scheduling, paper-based records, and phone-based coordination with a modern, centralized digital solution.

It enables:

- Efficient caretaker assignment  
- Leave and attendance tracking  
- Complaint and feedback handling  
- Service booking and payment management  
- Real-time dashboards and reports  

---

## 🎯 Project Goal

To design and implement a centralized, user-friendly caretaker management platform that:

- Simplifies service booking and assignment  
- Enhances communication between users  
- Improves operational efficiency  
- Ensures transparency and accountability  
- Supports secure role-based access  

---

## 👥 User Roles

### 🔹 Admin (Caretaker Company)
- Manage users (HR, Caretakers, Clients)
- Manage services
- View system-wide reports
- Monitor payments
- View leave requests
- Manage feedback & ratings
- Dashboard analytics

### 🔹 HR Manager
- Assign caretakers to clients
- Approve/reject leave requests
- Track attendance
- Manage caretaker schedules
- Handle client complaints
- Assign/remove priority status
- Generate service reports

### 🔹 Caretaker (Elder Care / Maid / Babysitter)
- View & update profile
- View assigned clients & schedules
- Apply for leave
- View leave status/history
- Mark attendance (Check-in/Check-out)
- View feedback & ratings
- Update availability
- View notifications

### 🔹 Client (Elder or Family)
- Register & login
- View available caretakers (with filters)
- View profile, ratings, availability
- Book services
- Make advance payment
- View booking & payment history
- Submit complaints
- Give feedback & rating
- Cancel or reschedule bookings
- Change caretaker

- Role-based authentication
- Encrypted password handling
- Session-based login control
- Restricted access per user role
- Secure data storage practices

---

## 💳 Payment Mechanism

- Clients pay an **advance payment** when booking a service.
- Remaining balance is paid after service completion.
- System tracks payment history and status.
- Admin can view financial summaries and reports.
